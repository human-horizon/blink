# Атрибуты и модификаторы методов

## Контекст

После устранения parser memory explosion проверка Bevy останавливается на `#[inline] pub const fn` внутри `impl`. Циклы trait/impl не пропускают атрибуты и квалификаторы метода.

## Цель

Разбирать атрибуты, restricted visibility и `const` перед методами trait/impl.

## Что изменится

1. `internal/parser/parser.go` — обработка атрибутов и модификаторов в циклах методов.
2. `internal/parser/parser_test.go` — регрессионный тест.

## Критерии приёмки

- [ ] `#[inline] pub const fn method() {}` разбирается внутри impl.
- [ ] Атрибуты перед trait-методами пропускаются.
- [ ] Ошибки внутри методов не зацикливают parser.
- [ ] Полный CI проходит.
