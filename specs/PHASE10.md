# Phase 10 — Declarative Macros

## Цель
Добавить базовый синтаксис `macro_rules!` без параметров.

## Синтаксис

```rust
macro_rules! zero {
    () => 0
}

fn main() {
    let x = zero!();
}
```

## Поддержка

- Определение макроса с одним правилом `() => expr`.
- Вызов макроса как выражение: `name!()`.
- Раскрытие макроса происходит на этапе парсинга / проверки типов.

## Ограничения Phase 10
- Только правила без аргументов.
- Тело макроса — одно выражение.
- Нет метапеременных (`$x:expr`), повторений и hygienе.

## Критерии приёма
- Валидное определение и вызов проходят.
- Вызов несуществующего макроса / неправильный синтаксис отклоняются.
- Все тесты и `go vet` проходят.
