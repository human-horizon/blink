# Аргументы выражений-макросов

## Контекст

После поддержки item-level макровызовов парсер Bevy доходит до `assert_eq!(...)` внутри тестовых функций. Текущий expression macro parser принимает только пустые круглые скобки.

## Цель

Разбирать expression macro invocation с произвольным непрозрачным содержимым сбалансированных delimiters.

## Что изменится

1. `internal/parser/parser.go` — пропуск аргументов expression macro.
2. `internal/parser/parser_test.go` — регрессионный тест.

## Детали реализации

1. Поддержать `()`, `[]` и `{}` после `name!`.
2. Пропускать вложенные delimiters.
3. Сохранить имя макроса в существующем AST.
4. Не расширять и не типизировать неизвестные макросы на этом этапе.

## Критерии приёмки

- [ ] Пустой expression macro продолжает разбираться.
- [ ] Макровызов с аргументами разбирается.
- [ ] Вложенные delimiters разбираются.
- [ ] Незавершённый вызов отклоняется.
- [ ] Все тесты, `go vet` и `go build` проходят.
