# Заглушки стандартных trait для совместимости с Bevy

## Контекст

`archetype-test` полностью разбирается парсером, но checker выдаёт ошибки для стандартных Rust trait, исходники которых не загружаются: `Index`, `IndexMut` и `Into`. Часть диагностик является каскадной, однако неизвестные trait и отсутствие базовых методов остаются первичными ошибками.

## Цель

Добавить безопасные синтетические описания стандартных trait и их методов, чтобы checker продолжал семантическую проверку Bevy без ложных паник и уменьшил число первичных ошибок.

## Что изменится

1. `internal/checker/builtins.go` — добавить имена стандартных trait в реестр встроенных типов и сигнатуры методов `Index::index`, `IndexMut::index_mut`, `Into::into`.
2. `internal/checker/checker.go` — распознавать эти trait при сборе impl без ошибки `unknown trait`, использовать их synthetic method signatures и не вызывать `Equals` на отсутствующем типе.
3. `internal/checker/checker_test.go` — добавить регрессионный тест для trait impl с builtin trait.

## Детали реализации

1. Для synthetic trait использовать placeholder-типы параметров и результата, равные `nil`, только в местах, где конкретный тип недоступен.
2. Проверка placeholder-параметров должна принимать фактический аргумент, не ослабляя проверки обычных пользовательских trait.
3. Если builtin trait не содержит полной сигнатуры метода, checker не должен считать это ошибкой сигнатуры и не должен паниковать.
4. Не изменять исходники Bevy и не добавлять кеширование.

## Критерии приёмки

- [x] `Index` и `IndexMut` больше не дают `unknown trait` в `archetype-test`.
- [x] Вызовы `into()` на встроенных типах не дают ошибку отсутствующего метода.
- [x] `GOMEMLIMIT=1GiB go test -timeout=60s ./...` проходит.
- [x] `go vet ./...` и `go build ./...` проходят.
- [x] `blink check benchmarks/archetype-test` завершается без panic и сокращает число ошибок с 110 до 104.
