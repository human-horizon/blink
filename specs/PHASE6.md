# Phase 6 — Named Lifetimes

## Цель
Добавить именованные лайфтаймы и базовую их проверку для ссылок.

## Поддерживаемый синтаксис

### Объявление лайфтайма
```rust
fn foo<'a>(x: &'a i32) -> &'a i32 { x }
```

### Структуры с лайфтаймами
```rust
struct Wrap<'a> {
    value: &'a i32,
}
```

### Правила
- Лайфтайм параметра функции должен быть не короче лайфтайма возвращаемой ссылки, если она выводится из входа.
- Пока поддерживается только **равенство** (`'a == 'b`) или **статический** `'static`.
- Запрещено возвращать ссылку на локальные данные.
- Lifetime elision: `fn method(&self) -> &T` получает тот же лайфтайм, что и `&self`.

## Ограничения Phase 6
- Нет `'_`.
- Нет сложных lifetime bounds (`'a: 'b`).
- Нет проверки фактического времени жизни (только метки).
- Нет lifetime variance.

## Критерии приёма
- `blink check` принимает валидные примеры с лайфтаймами.
- Отклоняет возврат ссылки на локальную переменную.
- Все тесты и `go vet` проходят.
