# Вывод типа для `Default::default()`

## Контекст

В Rust вызов `Default::default()` получает ожидаемый тип из позиции, например из
поля struct literal. Checker без контекста возвращает для неизвестного статического
вызова `i32`, что создаёт ложные несовпадения с `HashMap`.

## Цель

Передавать ожидаемый тип struct-поля в проверку вызова `Default::default()`.

## Правило

Если значение поля — вызов `Default::default()` без аргументов, его типом является
тип поля. Для прочих вызовов применяется обычная проверка без ослабления типов.

## Приёмка

- [ ] `Default::default()` корректно инициализирует поле `i32`.
- [ ] `Default::default()` корректно инициализирует поле `HashMap<...>`.
- [ ] Неверный обычный вызов по-прежнему диагностируется.
- [ ] `go test`, `go vet`, `go build` и Bevy-проверка проходят.
