# Phase 11 — Unsafe Blocks

## Цель
Добавить синтаксис `unsafe` блоков.

## Синтаксис

```rust
fn main() {
    let x = unsafe { 42 };
}
```

## Поддержка

- Парсинг `unsafe { expr }`.
- Типизация как обычный блок (семантика unsafe минимальна).

## Ограничения Phase 11
- Нет специальных unsafe-операций (сырые указатели, разыменование и т.д.).
- `unsafe` просто разрешает синтаксис и проверяет внутренность.

## Критерии приёма
- Валидный unsafe-блок проходит.
- Невалидное содержимое внутри unsafe отклоняется.
- Все тесты и `go vet` проходят.
