# Группированные импорты Rust

## Контекст

После поддержки item-level макровызовов `bevy_ecs` останавливается на `use crate::{...};`. Текущий парсер поддерживает только линейный путь импорта.

## Цель

Распознавать группированные импорты с вложенными `{...}` и сохранять их как непрозрачный импорт до реализации полноценного разрешения каждого импортируемого имени.

## Что изменится

1. `internal/ast/ast.go` — признак группированного импорта.
2. `internal/parser/parser.go` — пропуск сбалансированной группы после `::`.
3. `internal/checker/checker.go` — не создавать фиктивный alias для группы.
4. `internal/parser/parser_test.go` — регрессионные тесты.

## Детали реализации

1. Поддержать `use path::{item, nested::{one, two}};` на синтаксическом уровне.
2. Проверять баланс вложенных фигурных скобок.
3. Не выдавать ложные имена для элементов группы.
4. Полное разрешение и проверку импортов группы оставить отдельной задачей.

## Критерии приёмки

- [ ] Линейный импорт продолжает работать.
- [ ] Группированный импорт разбирается.
- [ ] Вложенные группы разбираются.
- [ ] Незавершённая группа отклоняется.
- [ ] Все тесты, `go vet` и `go build` проходят.
