# Позиция parser-ошибок

## Контекст

На большом crate текущая ошибка `expected 1, got 47` не показывает место в исходнике, поэтому поиск следующей неподдерживаемой конструкции требует повторного анализа.

## Цель

Включать byte offset текущего токена в ошибки `expect`.

## Что изменится

1. `internal/parser/parser.go` — добавление offset в сообщение ошибки.
2. Существующие parser-тесты — проверка сохранения факта ошибки.

## Критерии приёмки

- [ ] Ошибка `expect` содержит offset.
- [ ] Существующие тесты проходят.
- [ ] `go vet` и `go build` проходят.
