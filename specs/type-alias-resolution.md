# Строгое разрешение type alias

## Контекст

Checker регистрирует структуры, функции и traits, но не разрешает `TypeAliasDecl`.
Из-за этого псевдоним `ComponentIndex` остаётся отдельным именованным типом вместо
эквивалентного `HashMap<...>`. Нужно реализовать семантику Rust без глобальных
совместимостей и wildcard-правил.

## Цель

Разрешать локальные и модульные type alias рекурсивно, подставляя параметры
псевдонима и обнаруживая циклические определения.

## Изменения

- `internal/ast/ast.go` — хранить generic-параметры alias.
- `internal/parser/parser.go` — разбирать параметры в объявлении alias.
- `internal/checker/checker.go` — регистрировать alias, разрешать их в `resolveType`,
  подставлять generic-параметры и обнаруживать циклы.
- `internal/checker/checker_test.go` — регрессионные тесты.

## Строгие правила

- `type Id = i32` эквивалентен `i32`.
- `type Pair<T> = (T, T)` подставляет `T` только в рамках alias.
- Неизвестный alias — ошибка.
- Цикл `type A = B; type B = A;` — ошибка.
- Alias не создаёт новый nominal type.
- Никаких Bevy-specific wildcard/coercion правил.

## Критерии приёмки

- [ ] Простой alias корректно проверяет присваивание.
- [ ] Generic alias корректно подставляет параметры.
- [ ] Alias через `use`/модуль разрешается.
- [ ] Циклический alias выдаёт диагностическую ошибку без зависания.
- [ ] Регрессионные тесты проходят.
- [ ] `go test`, `go vet`, `go build` проходят.
- [ ] Bevy-проверка измеряет изменение оставшихся ошибок.
