# Phase 7 — Patterns / Destructuring

## Цель
Добавить базовые паттерны для деструктуризации структур.

## Поддерживаемый синтаксис

### Идентификатор / wildcard
```rust
let x = 1;
let _ = 2;
```

### Деструктуризация структуры
```rust
struct Point { x: i32, y: i32 }
let p: Point = Point { x: 1, y: 2 };
let Point { x, y } = p;
```

### Игнорирование поля
```rust
let Point { x, .. } = p;
```

## Ограничения Phase 7
- Паттерны только в `let`.
- Пока нет tuple-паттернов, enum-паттернов, `if let`, `match`.
- Поля можно переименовывать: `let Point { x: x1, y: y1 } = p;`.

## Критерии приёма
- Валидная деструктуризация проходит.
- Неверное имя поля / нехватка полей отклоняется.
- Все тесты и `go vet` проходят.
