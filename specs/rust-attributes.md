# Поддержка Rust-атрибутов

## Контекст

После поддержки Cargo-layout проверка Bevy достигает `bevy/src/lib.rs`, но останавливается на `#![cfg_attr(...)]`. Атрибуты Rust не должны ломать разбор, даже если blink пока не реализует их семантику.

## Цель

Распознавать и безопасно пропускать внешние и внутренние атрибуты Rust перед объявлениями, сохраняя их исходные позиции для последующих этапов развития компилятора.

## Что изменится

1. `internal/lexer/token.go` — токен символа `#`.
2. `internal/lexer/lexer.go` — лексема `#`.
3. `internal/parser/parser.go` — пропуск сбалансированных атрибутов перед объявлениями.
4. `internal/parser/parser_test.go` и `internal/lexer/lexer_test.go` — регрессионные тесты.

## Детали реализации

1. Поддержать формы `#[...]` и `#![...]`.
2. Пропускать вложенные квадратные скобки внутри атрибута.
3. Вызывать пропуск атрибутов до каждого top-level объявления.
4. Не интерпретировать условия `cfg` и не включать/исключать код на этом этапе.
5. Возвращать понятную ошибку для незавершённого атрибута.

## Критерии приёмки

- [ ] `#![no_std]` перед объявлением разбирается.
- [ ] `#[cfg(...)]` перед объявлением разбирается.
- [ ] Сбалансированные вложенные скобки пропускаются.
- [ ] Незавершённый атрибут возвращает ошибку.
- [ ] Существующие тесты, `go vet` и `go build` проходят.
