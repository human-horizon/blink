# Тип `Self` в позициях типа

## Контекст

После поддержки tuple/unit-структур `bevy_ecs` останавливается на `Self` в типе возвращаемого значения метода. Lexer уже распознаёт `Self`, но `parseType` принимает только идентификаторы и примитивы.

## Цель

Разрешить `Self` как именованный тип в AST, чтобы checker мог применить существующую логику `Self` для trait/impl-контекста.

## Что изменится

1. `internal/parser/parser.go` — обработка токена `Self` в `parseType`.
2. `internal/parser/parser_test.go` — регрессионный тест.

## Критерии приёмки

- [ ] `fn method() -> Self { ... }` разбирается.
- [ ] `Self` внутри tuple-типа разбирается.
- [ ] Некорректное использование `Self` отклоняется checker-ом вне impl/trait.
- [ ] Все тесты, `go vet` и `go build` проходят.
