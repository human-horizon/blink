# Глобальные импорты Rust

## Контекст

После пропуска атрибутов проверка Bevy останавливается на `pub use bevy_internal::*;`. Текущий AST и парсер поддерживают только импорт конкретного имени.

## Цель

Распознавать синтаксис `use path::*;` и сохранять его в AST, не выдавая ложную синтаксическую ошибку.

## Что изменится

1. `internal/ast/ast.go` — признак глобального импорта в `UseDecl`.
2. `internal/parser/parser.go` — разбор `::*`.
3. `internal/checker/checker.go` — безопасное сохранение глобального импорта без выдумывания доступных внешних имён.
4. Тесты AST/parser/checker — регрессии для glob-импорта.

## Детали реализации

1. Разрешить `*` только после `::` в `use`-пути.
2. Для glob-импорта не создавать фиктивный alias `*`.
3. Полное расширение имён из glob-импорта оставить отдельной задачей разрешения внешних crate.
4. Некорректные формы по-прежнему должны завершаться диагностикой.

## Критерии приёмки

- [ ] `use bevy_internal::*;` разбирается.
- [ ] `pub use bevy_internal::*;` разбирается.
- [ ] Glob-импорт не создаёт alias `*`.
- [ ] Существующие импорты и ошибки продолжают работать.
- [ ] Все тесты, `go vet` и `go build` проходят.
