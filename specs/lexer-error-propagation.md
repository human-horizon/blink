# Передача ошибок лексера

## Контекст

Лексер устанавливает ошибку при встрече неподдерживаемого символа и возвращает `EOF`. Парсер завершает разбор на `EOF`, но не проверяет ошибку лексера. В результате файл с неподдерживаемой конструкцией может ошибочно пройти `blink check`.

## Цель

Гарантировать, что любая ошибка лексера превращается в ошибку разбора и возвращается CLI с ненулевым кодом.

## Что изменится

1. `internal/parser/parser.go` — проверка ошибки лексера после разбора файла.
2. `internal/parser/parser_test.go` — тест неподдерживаемого символа.

## Детали реализации

1. После основного цикла `ParseFile` проверять `p.l.Err()`.
2. Возвращать ошибку лексера, если синтаксическая ошибка парсера ещё не была установлена.
3. Сохранить существующий приоритет первой ошибки парсера.

## Критерии приёмки

- [ ] Исходник с неподдерживаемым символом возвращает ошибку парсинга.
- [ ] CLI отклоняет такой исходник.
- [ ] Все существующие тесты проходят.
- [ ] `go vet` и `go build` проходят.
