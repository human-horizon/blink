# Phase 5 — Modules

## Цель
Добавить базовую систему модулей: разделение кода по файлам, публичные/приватные элементы, импорт через `use`.

## Поддерживаемый синтаксис

### Объявление модуля
```rust
mod foo;      // загружает файл foo.rs из той же директории
mod bar {     // inline-модуль
    fn inner() {}
}
```

### Видимость
- По умолчанию элементы приватные внутри модуля.
- `pub fn`, `pub struct`, `pub enum`, `pub trait`, `pub mod` делают элемент видимым снаружи модуля.

### Импорт
```rust
use foo::bar;        // импортирует `bar` из модуля `foo` в текущую область
use foo::bar as b;   // alias
```

### Обращение по пути
```rust
foo::bar::baz();
```

## Ограничения Phase 5
- `mod name;` ищет файл `name.rs` в той же директории.
- `pub` работает только на «одном уровне»: `pub fn` в модуле видно родителю, но не видно за пределами родителя без `pub use` или повторного `pub`.
- Нет `pub(crate)`, `pub(super)`, `pub(in path)`.
- Нет re-exports (`pub use`).
- Нет `self::` / `super::` / `crate::`.
- Каждый файл — единый модуль; нет `mod.rs`.

## Критерии приёма
- `blink check <dir>` обрабатывает `main.rs` и все `mod foo;`.
- Cross-file функции/типы разрешаются.
- Приватный элемент из другого модуля вызывает ошибку.
- `go test ./...` и `go vet ./...` без ошибок.
