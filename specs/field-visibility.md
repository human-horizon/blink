# Видимость полей структур

## Контекст

После устранения parser memory explosion проверка Bevy останавливается на `pub` у поля структуры. Parser поддерживает видимость объявлений, но не полей.

## Цель

Пропускать модификатор видимости поля, сохраняя существующую модель полей.

## Что изменится

1. `internal/parser/parser.go` — пропуск `pub` и `pub(...)` перед полями структур.
2. `internal/parser/parser_test.go` — регрессионный тест.

## Критерии приёмки

- [ ] `struct Item { pub value: i32 }` разбирается.
- [ ] `struct Item { pub(crate) value: i32 }` разбирается.
- [ ] Tuple-структуры с видимостью полей разбираются.
- [ ] Полный CI проходит.
