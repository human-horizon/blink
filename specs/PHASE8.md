# Phase 8 — Tuples, const, static

## Цель
Добавить tuple-типы и tuple-выражения, а также объявления `const` и `static`.

## Tuples

### Тип
```rust
let t: (i32, bool) = (1, true);
```

### Доступ к элементу
```rust
let x = t.0;
let b = t.1;
```

### Деструктуризация
```rust
let (x, b) = t;
```

## const и static

```rust
const MAX: i32 = 100;
static COUNTER: i32 = 0;

fn main() {
    let x = MAX;
    let y = COUNTER;
}
```

- `const` доступны только для чтения и должны быть инициализированы литералом.
- `static` — глобальная переменная; `mut static` запрещён в Phase 8.

## Ограничения
- Tuple доступ только по литеральному индексу (`t.0`).
- Const/static инициализаторы ограничены примитивами/строками (без вызовов функций).

## Критерии приёма
- Корректные tuple и const/static проходят.
- Неверный индекс / несовпадение типов отклоняется.
- Все тесты и `go vet` проходят.
